## 兼容性

- 此模组使用 Forge 47.4.20 与 Minecraft 1.20.1 编写
- 版本相近的相关依赖项虽然理应能够正常运行，但不保证能避免一切严重问题。
- 暂时没有发现不兼容模组

## 构建

1. 使用 Git 克隆此仓库或下载源代码解压
2. 使用 IntelliJ IDEA 打开
3. 导入完成后，运行

```bash
gradlew build
```

4. 项目生成的 `build` 目录下，可以找到生成的 Jar
