You’ll have to clone it to the local and compile it yourself to get the mod JAR.

## Compatibility

- This mod is built with Forge 47.4.20 and Minecraft 1.20.1.
- Related dependencies with similar versions should generally work, but we can't guarantee it will prevent all serious issues.
- No incompatible mods have been found so far.

## Build

1. Clone this repository using Git or download the source code and unzip it.
2. Open it with IntelliJ IDEA
3. After importing, run
```bash
gradlew build
```
4. You can find the generated JAR in the `build` directory of the project.
