## Сборка

1. Клонируйте этот репозиторий с помощью Git или скачайте исходный код и распакуйте его
2. Откройте в IntelliJ IDEA
3. После импорта выполните

```bash
gradlew build
```

4. В сгенерированном проекте в папке `build` можно найти созданный Jar
